# `s3` — AWS S3

**Code**: `internal/driver/s3/`

Reads S3 objects or lists objects under a prefix (phase 1 is Select-focused).

## Capabilities

| Select | Insert | Update | Delete | Upsert | Invoke |
|--------|--------|--------|--------|--------|--------|
| ✓ | ✗ | ✗ | ✗ | ✗ | ✗ |

## Server `options`

| Field | Required | Description |
|-------|----------|-------------|
| `bucket` | ✓ | S3 bucket name |
| `region` | | AWS region (may also be set in credential) |

## Credential

| Field | Description |
|-------|-------------|
| `accessKeyId` | AWS access key |
| `secretAccessKey` | AWS secret |
| `sessionToken` | Optional STS token |
| `region` | Overrides `options.region` |

When static keys are omitted, the AWS default credential chain applies (IAM role, env vars, etc.).

## Table `options`

| Field | Description |
|-------|-------------|
| `prefix` | Object key prefix or single object key; defaults to `remoteName` |
| `format` | `json` · `csv` · `ndjson`; inferred from extension when present |

- With `format` set or a key extension present: download and parse that object.
- Otherwise: `ListObjectsV2`, returning `key` and `size` columns.

## Example

```yaml
servers:
  - name: exports
    protocol: s3
    credential:
      accessKeyId: ${AWS_ACCESS_KEY_ID}
      secretAccessKey: ${AWS_SECRET_ACCESS_KEY}
      region: ap-southeast-1
    options:
      bucket: my-data-lake

tables:
  - server: exports
    name: orders
    remoteName: exports/orders.ndjson
    options:
      format: ndjson
```

## Notes

- Writes are not implemented yet.
- Large objects are fully loaded into memory before filtering.
